# Portafolio de Servicios

Una aplicación de Portafolio de Servicios interactiva y profesional construida con **Angular**. Este proyecto muestra habilidades, experiencia y proyectos de una manera moderna, responsiva y visualmente atractiva.

[![Demo en Vercel](https://img.shields.io/badge/demo-vercel-%23000000?style=for-the-badge&logo=vercel&logoColor=white)](https://edwinnino-service-portfolio.vercel.app/)

## 🚀 Demo en Vivo

Se puede ver el despliegue en vivo en la siguiente URL:
[https://edwinnino-service-portfolio.vercel.app/](https://edwinnino-service-portfolio.vercel.app/)

## Características

- **Inicio**: Página de bienvenida con una breve introducción.
- **Experiencia**: Implementación de línea de tiempo o lista de experiencia profesional.
- **Proyectos**: Exhibición de proyectos anteriores, incluyendo "RAAADIO".
- **Habilidades**: Representación visual de habilidades técnicas y competencias.
- **Contacto**: Formulario de contacto o información para posibles consultas.
- **Diseño Responsivo**: Optimizado para varios tamaños de pantalla (móvil, tableta, escritorio).
- **Tematización**: Estilos personalizados utilizando SCSS.

## Stack Tecnológico

- **Framework**: [Angular](https://angular.io/) (v21.1.4)
- **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
- **Estilos**: SCSS / CSS
- **Herramienta de Construcción**: Angular CLI
- **Gestor de Paquetes**: npm

## Instalación

1.  **Clonar el repositorio:**
    ```bash
    git clone <repository-url>
    cd service-portfolio
    ```

2.  **Instalar dependencias:**
    ```bash
    npm install
    ```

## Uso

### Servidor de Desarrollo

Ejecuta `ng serve` para un servidor de desarrollo. Navega a `http://localhost:4200/`. La aplicación se recargará automáticamente si cambias cualquiera de los archivos fuente.

```bash
npm start
```

### Construcción

Ejecuta `ng build` para construir el proyecto. Los artefactos de construcción se almacenarán en el directorio `dist/`.

```bash
npm run build
```

### Ejecutar Pruebas

Ejecuta `ng test` para ejecutar las pruebas unitarias a través de [Vitest](https://vitest.dev/).

```bash
npm test
```

## Estructura del Proyecto

```
src/
├── app/
│   ├── features/       # Módulos de funcionalidad (Inicio, Proyectos, Habilidades, etc.)
│   ├── layout/         # Componentes de diseño (Encabezado, Pie de página, Diseño Principal)
│   ├── app.routes.ts   # Configuración de rutas de la aplicación
│   └── ...
├── assets/             # Activos estáticos (imágenes, iconos, etc.)
├── styles.scss         # Estilos globales
└── main.ts             # Punto de entrada de la aplicación
```
